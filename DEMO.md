# 60-second demo script

**Preparation (before recording):** Install dependencies and an Ollama instruct model, start Ollama and Streamlit, and copy `sample_files` to a disposable folder. Keep the folder visible. Model inference time depends on hardware, so prewarm the model if needed; do not claim the full inference always finishes in 60 seconds.

| Time | Action and narration |
| --- | --- |
| 0–10 s | Show messy filenames. “These files tell us little about their contents.” |
| 10–20 s | In LazyRename, enter the copied folder path, show the selected local model, and click **Scan and suggest names**. “The model reads bounded content locally; it never sees the old name.” |
| 20–35 s | Show the editable preview. Change one suggestion manually and deselect another. “I decide what actually gets renamed.” |
| 35–45 s | Check the confirmation box and rename. Show the before-and-after table and explain that the time figure is an assumption, not a benchmark. |
| 45–55 s | Click **Undo most recent rename batch** and show the original names restored. |
| 55–60 s | “No paid API or keys. The content stays on this computer.” |

If inference takes longer, pause the recording during model generation and disclose that edit in the final video.
